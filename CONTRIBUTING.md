# Contributing

Issues and suggestions are welcome.

Code contributions outside `vendor/` can be accepted only with a copyright assignment to the
maintainer. The project is GPL-3.0-or-later today and may later be relicensed (for example to MIT),
which is only possible while one person holds the copyright of everything outside `vendor/`. Code
under `vendor/` keeps its upstream licence. So do the few files in `spikes/` adapted from engine code
(Karballo, MIT; Pirarucu, GPL-3.0), which say so in a header; the spikes are experiments and not part
of the Tool.
